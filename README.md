# JukeBox.png

JukeBox.png is a Discord bot that can connect to voice channels and transcribe audio into text, make recordings, and play them back at random. It can also connect to AI endpoints to request summaries for conversations or build a profile of a server member based on their communication.

## Features

- Connects to Discord voice channels
- Transcribes audio into text
- Records voice audio
- Plays recordings back at random
- Connects to AI endpoints
- Requests summaries for conversations
- Builds server member profiles based on their communication
