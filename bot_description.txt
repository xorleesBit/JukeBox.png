# Техническая Документация Loger Bot v5.0

## 1. Введение
Loger Bot — это многофункциональный Discord-бот для голосовых серверов, специализирующийся на записи разговоров, транскрибации речи в текст (STT), геймификации общения (экономика, RPG-элементы) и развлечениях на базе ИИ.

Бот спроектирован для работы в контейнеризированной среде (Docker), использует асинхронную архитектуру для высокой производительности и PostgreSQL для надежного хранения данных.

---

## 2. Стек Технологий

### Языки и Фреймворки
*   **Python 3.11+**: Основной язык разработки.
*   **discord.py 2.4+**: Взаимодействие с Discord API.
*   **discord-ext-voice-recv**: Библиотека для получения аудиопотока из голосовых каналов.

### Обработка Аудио
*   **Silero VAD v5+ (ONNX)**: Нейросеть для детектирования человеческой речи (Voice Activity Detection). Работает локально, используется для фильтрации тишины и экономии трафика.
*   **FFmpeg & Pydub**: Обработка аудиофайлов (конвертация, нормализация, нарезка).
*   **Azure Speech-to-Text**: Облачный сервис Microsoft для перевода голоса в текст.

### База Данных и Хранение
*   **PostgreSQL 15**: Основная реляционная БД (хранит пользователей, экономику, настройки).
*   **asyncpg**: Асинхронный драйвер для PostgreSQL (обеспечивает высокую скорость запросов).
*   **Файловая система**: Логи и аудиозаписи хранятся локально в структурированных папках, проброшенных через Docker Volumes.

## 3. Архитектура Системы

Бот построен по модульной схеме. Точка входа — `bot_entry.py`.

### 3.1. Ядро (Core)
*   **`bot_entry.py`**: Инициализация бота, загрузка расширений (Cogs), обработка сигналов завершения (Graceful Shutdown).
*   **`AppDB` & `sql.py`**: Слой доступа к данным. Все SQL-запросы вынесены в `sql.py` для чистоты кода. Реализована система автоматических миграций при старте.
*   **`RuntimeSettings`**: Кэшируемые настройки гильдий, позволяющие менять параметры без лишних запросов к БД.

### 3.2. Система Записи (Voice Logger)
Это сердце бота. Работает в несколько этапов, чтобы не блокировать основной поток (Event Loop):

1.  **Захват (Sink)**:
    *   `TimeStampedSink` перехватывает UDP-пакеты Opue/PCM от Discord.
    *   **Оптимизация**: Данные не хранятся в RAM. Используется `DiskPacketBuffer`, который сбрасывает пакеты во временный файл на диске. Это позволяет писать часами, потребляя минимум памяти.

2.  **Обработка (Worker)**:
    *   `ChunkProcessor` — фоновый поток (Thread), который забирает накопленные пакеты (Chunks).
    *   **Smart Trim**: Анализирует пакеты, находит начало и конец речи, обрезает лишнюю тишину.
    *   **VAD & Emotion**: Прогоняет аудио через Silero VAD для проверки на наличие речи. Анализирует громкость для тегов `[LOUD]`, `[SCREAM]`.
    *   **Stream Append**: Использует алгоритм потоковой склейки, игнорирующий джиттер (микро-паузы) для создания плавного звука.

3.  **Транскрибация (STT)**:
    *   Если VAD подтвердил наличие речи, файл конвертируется в **16kHz Mono** (стандарт для Azure).
    *   Отправляется в Azure STT. Полученный текст сохраняется в JSONL-лог и БД (статистика слов).

### 3.3. Пранк-система
*   **`PrankManager`**: Управляет записью "ударных фраз" для саундпада.
*   **`PrankSampler`**: Постоянно слушает буфер. Если возникает тишина после всплеска громкости — вырезает фразу и сохраняет её как потенциальный пранк.

## 4. Функционал и Механики

### 4.1. Экономика и RPG
*   **Валюта**: Монеты. Зарабатываются активностью в чате, голосе (XP loop) и `!daily`.
*   **Магазин (`!shop`)**: Покупка баффов.
*   **Баффы (BuffManager)**:
    *   🧪 *XP Potion*: Увеличивает опыт.
    *   🕶️ *Ghost Cloak*: Скрывает от записи (VoiceLogger игнорирует аудиопоток).
    *   🛡️ *Mirror*: Отражает атаки `!roast`.
    *   🎫 *Sound Pass*: Бесплатная загрузка звуков.
*   **Инвентарь**: Хранение и активация предметов. Эффекты суммируются по времени.

### 4.2. Искусственный Интеллект (AI)
*   **Smart Summary**: Раз в сутки `LogArchiver` объединяет логи, отправляет их в LLM и создает краткую выжимку событий (Markdown отчет).
*   **Fun AI**:
    *   `!roast`: Прожарка пользователя на основе его реальных логов (контекстный анализ).
    *   `!joke`: Добрая шутка на основе контекста.
    *   `!month_recap`: Итоговый отчет за месяц по всем архивам.

### 4.3. Администрирование и Debug
*   **`!debug` (DM Only)**: Мощная панель разработчика.
    *   Просмотр загрузки системы (CPU/RAM).
    *   Чтение логов ошибок прямо в чате.
    *   SQL-консоль для прямых запросов к БД.
    *   Управление любым сервером (выдача админки, рестарт).
*   **Панель Управления**: Сообщение в канале `loger-control` с кнопками для управления записью, плеером и архивами.

### 4.4. Саунд-пад
*   Пользователи могут загружать свои звуки (`!upload_sound`) за монеты.
*   Валидация файлов (размер, длительность, тишина).
*   Воспроизведение через меню `!pad` или кнопку в профиле.

## 5. Особенности реализации

### Безопасность
*   **Изоляция**: Все команды удаления работают только в пределах текущего `guild_id`. Избранные фразы (`is_favorite=True`) защищены от массового удаления.
*   **Graceful Shutdown**: При остановке контейнера бот завершает текущие задачи, сохраняет буферы на диск и только потом отключается.

### Оптимизация
*   **VAD**: Универсальный адаптер поддерживает любые версии Silero (v3, v4, v5, v6).
*   **Azure Cost**: Пустые файлы и тишина не отправляются. Файлы обрезаются (`Smart Trim`). Используется пакетная обработка.
*   **Log Archiver**: Старые логи автоматически сжимаются и архивируются, освобождая иноды файловой системы.
